# 📝 Daily Task Manager - OIBSIP Internship Project

![Project Banner](https://img.shields.io/badge/Status-Completed-brightgreen) ![Language](https://img.shields.io/badge/Language-JavaScript-yellow) ![HTML](https://img.shields.io/badge/HTML-CSS-JS-blue)

---

## 🎯 Objective
Create a *web-based Daily Task Manager* that allows users to:  
- Track pending and completed tasks  
- Set reminders for tasks  
- Manage time efficiently with AM/PM format  
- Toggle between light and dark mode for professional UI  

---

## 🛠 Tools & Technologies Used
- *Languages:* HTML, CSS, JavaScript  
- *Storage:* LocalStorage for persisting tasks  
- *Editor:* VS Code  
- *Browser:* Google Chrome / any modern browser  

---

## ✨ Features
- Add tasks with *name, date, and time*  
- Display time in *AM/PM format*  
- Mark tasks as *Pending* or *Completed*  
- Delete tasks  
- Dark mode toggle for professional appearance  
- Responsive layout for mobile and desktop  
- Reminder options (5, 10, 30 minutes before task)  
- Smooth hover animations for task cards  

---

## 🛠 Implementation Steps
1. *Planned UI layout:* Login screen, task input, task lists  
2. *Built HTML structure:* Login, task input sidebar, pending & completed lists  
3. *Styled UI:* Glass-card effect, dark mode, responsive grid layout  
4. *Implemented JS functionality:*  
   - Login / Logout  
   - Add, delete, complete/reopen tasks  
   - LocalStorage integration to persist tasks  
   - Convert 24-hour time to AM/PM  
5. *Tested app:* Checked responsiveness, dark mode, and smooth functionality  

---

## 🏆 Outcome
- Fully functional *Daily Task Manager web application*  
- Tasks are persistent across sessions  
- Professional, modern UI with dark mode  
- Easy task management with pending/completed separation  
- Clean, intuitive user experience
